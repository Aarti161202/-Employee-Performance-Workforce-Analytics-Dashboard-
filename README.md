# -Employee-Performance-Workforce-Analytics-Dashboard-
📌 Project Overview  The Employee Performance &amp; Workforce Analytics Dashboard is a data analytics and visualization project designed to analyze employee performance, workforce trends, salary distribution, and departmental insights. The dashboard provides an interactive way to explore employee data and identify patterns that can support data-driven workforce decisions.

🎯 Project Objectives
Analyze employee performance across different departments.
Compare employee salaries and performance scores.
Identify high-performing employees.
Analyze workforce distribution by department and role.
Understand salary trends across departments.
Provide interactive insights using filters and visualizations.
📊 Dashboard Features
Total Employees
Average Salary
Average Performance Score
Department-wise Employee Distribution
Salary vs. Performance Analysis
Employee Performance Comparison
Department-wise Salary Analysis
High Performer Identification
Interactive Department and Performance Filters
📈 Key Visualizations
KPI Cards – Employee count, average salary, and performance score
Bar Chart – Employees by department
Scatter Plot – Salary vs. Performance Score
Bar Chart – Average salary by department
Performance Analysis – Employee performance comparison
Filters/Slicers – Department, role, and performance-related analysis
🛠️ Tools & Technologies
Power BI / Tableau
Microsoft Excel / CSV
Data Cleaning & Transformation
Data Analysis
Calculated Fields / Measures
Interactive Dashboard Design
Data Visualization
💡 Key Insights

The dashboard helps identify relationships between salary and employee performance, compare performance across departments, and understand workforce distribution. It provides a consolidated view of employee-related metrics for easier analysis and reporting.
